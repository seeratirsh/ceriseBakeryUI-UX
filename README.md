# 🍒 Cerise Patisserie

Cerise is a luxury bakery website concept inspired by modern Apple product pages and high-end Parisian patisseries. The goal was to create a premium digital experience that feels elegant, refined, and immersive—just like walking into a boutique pastry shop in Paris.

Instead of the colorful and playful style commonly seen in bakery websites, Cerise focuses on minimalism, sophisticated typography, rich photography, and smooth animations to showcase artisan cakes as luxury products.

---

## ✨ About The Project

This project was built to explore premium UI design, advanced animations, and modern frontend development.

The design combines:

* Apple-inspired layouts
* Editorial-style product presentation
* Luxury e-commerce aesthetics
* Smooth micro-interactions
* Elegant typography and spacing

Every section is designed to highlight craftsmanship, quality, and attention to detail.

## 📂 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/cerise-patisserie.git
```

Navigate into the project:

```bash
cd cerise-patisserie
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:5173
```
